
# Working paper

This is a repo with code for the simulation study "Simulation-based cutoffs for conditional item fit in Rasch models: iterations, interval width, and multiplicity". It is work in progress and the `index.pdf` manuscript file will be updated with a new date when it is re-rendered with an updated version. The main manuscript is in `index.qmd`.

A preprint has been uploaded to PsyArXiv at: <https://doi.org/10.31234/osf.io/7pqz4_v1>
